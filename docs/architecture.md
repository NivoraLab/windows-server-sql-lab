# Architecture

## Environment

The project was implemented in a virtualized environment using VMware Workstation.

### Components

- Host system
- VMware Workstation
- Windows Server virtual machine
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Project database

## Architecture Overview

The Windows Server virtual machine provides the environment for the SQL Server installation and database administration.

SQL Server Management Studio was used to configure and manage the database, users, permissions, data imports, backups and recovery procedures.
