# Backup & Recovery

## Overview

This part of the project focused on database backup, restore and recovery using Microsoft SQL Server.

The goal was to verify that the database could be backed up and successfully restored after a simulated recovery scenario.

## Tasks performed

- Created a database backup
- Verified the backup file
- Performed a database restore
- Tested the restored database
- Verified database integrity after recovery

## Tools

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Result

The database was successfully restored and tested after the recovery procedure.

This demonstrated the basic process of protecting and recovering data in a SQL Server environment.
